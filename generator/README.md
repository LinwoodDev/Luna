# Luna Generator

> Generate static websites with templates

Luna Generator is a small Rust library for producing static pages from route paths, strings, and template engines. Luna CLI uses it for generated registry docs, but it is designed to be usable by other tools that need a simple static-site writer.

```rust
use luna_generator::StaticSite;

let mut site = StaticSite::new();
site.add_page("index.html", "<h1>Hello</h1>");
site.add_page("docs/getting-started.html", "<p>Generated by Luna Generator.</p>");
site.write_to("dist")?;
# Ok::<(), Box<dyn std::error::Error>>(())
```

With the `handlebars` feature enabled, you can render pages from a registered Handlebars template engine and write the generated site to any output directory.
